Предназначен для тех, кто хочет сохранить свой индивидуальный стиль, не
жертвуя защитой. В каждую коробку входит полный набор литых керамических
пластин и сегментов из баллистического волокна, предназначенных для
крепления к вашей любимой одежде и подходящих для любого типа
телосложения. Превратите ваш любимый свитер в ваш любимый бронированный свитер без всяких хлопот с шитьем!<br>

Комплект Мимической Одежды можно соединить с любой модной курткой или
топом, чтобы превратить ее в Легкий Бронекостюм Для Тела с появлением
соответствующего Стиля. После соединения снять бронепластины будет невозможно.<br>
Из каждого комплекта можно изготовить одну Броню для Тела.
