Классика 2020-х. Любимый всеми ручной огнемёт,
который по-прежнему приносит огненное разрушение прямо к твоим пальцам.<br>

Одноручный экзотический дробовик с 2 выстрелами,
стреляющий с использованием навыка тяжёлое оружие
вместо навыка длинноствольное оружие. Механически
этот огнемёт считается ружьём, которое может стрелять
только зажигательными патронами для дробовиков.
Пока цель горит, она получает 4 урона по ПЗ в конце своего хода, пока не потратит действие, чтобы потушить себя. Если цель уже горела, этот эффект заменяет
предыдущий, если он наносил меньший урон.<br>
Множественные источники этого эффекта не суммируются.
Урон, наносимый этим оружием, не может вызвать критическое повреждение, и оно не может использоваться
для прицельных выстрелов.
