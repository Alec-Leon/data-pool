При попадании сеть захватывает цель. Одновременно цель может быть
захвачена только одной сетью. Пока цель захвачена сетью, она не может
использовать движение. Цель в сети не может использовать двуручное оружие, и получает -2 ко всем физическим действиям до тех пор, пока остается в
сети. Сеть имеет 15 ПЗ и уничтожается без возможности восстановления,
когда ПЗ достигают 0. Стрельба из дальнобойного оружия из вне в сеть
наносит равные повреждения сети и цели, захваченной ею. Для того чтобы
вырваться из сети, требуется проверка Акробатики СЛ 13, которую может
выполнить только цель, находящаяся в сети, или проверка Рукопашного Боя
СЛ 13, которую может выполнить любой.<br>

При успешном выполнении любой
из этих проверок сеть разрушается и не подлежит восстановлению.
